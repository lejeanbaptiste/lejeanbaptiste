# LJB corpus import extension

Unpacked Manifest V3 extension for Brave (or Chrome). Sends the current **Wikisource** or **Kanripo** page to Le Jean-Baptiste.

1. Start **Le Jean-Baptiste** once (writes native-messaging manifests).
2. `brave://extensions` → Developer mode → Load unpacked → this folder.
3. Open a Wikisource page or a Kanripo text (`#KR1a0030_001` in the URL) and click **Import**.

See [docs/wikisource-import.md](../../docs/wikisource-import.md) (Wikisource) and [docs/kanripo-import-plugin-planning.md](../../docs/kanripo-import-plugin-planning.md) (Kanripo).
