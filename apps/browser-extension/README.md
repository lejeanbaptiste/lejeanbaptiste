# LJB Wikisource extension

Unpacked Manifest V3 extension for Brave (or Chrome).

1. Start **Le Jean-Baptiste** once (writes native-messaging manifests).
2. `brave://extensions` → Developer mode → Load unpacked → this folder.
3. Open a Wikisource work or chapter and click **Import**.

See [docs/wikisource-import.md](../../docs/wikisource-import.md).
