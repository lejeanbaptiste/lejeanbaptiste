the chunk — never emit a suggestion whose surface string falls only in the

and never include a shad ("།", "༎", "༏") — those are punctuation, not part of

Do not invent text that is not present in the chunk. Do not use character
offsets. Return only JSON matching the schema — no prose, no markdown fences.
